# Calculator OOP Project

Simple calculator built using Java OOP concepts.

## Features
- Add, Subtract, Multiply, Divide
- Stores last result
- Keeps history of last 10 operations
- Encapsulation using private fields

## Technologies
- Java
- OOP
- Arrays

## How to run
1. Compile:
   javac Main.java Calculator.java
2. Run:
   java Main
